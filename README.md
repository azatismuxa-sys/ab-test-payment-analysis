# ab-test-payment-analysis
A/B testing analysis of a new utility payment form using Python

# A/B-тест новой формы оплаты ЖКХ

# О проекте
Анализ результатов A/B-тестирования новой формы оплаты ЖКХ с автоматическим заполнением реквизитов.

Цель исследования — определить, увеличивает ли новая форма конверсию в успешную оплату.

# Инструменты
- Python
- pandas
- NumPy
- SciPy
- Matplotlib
- Jupyter Notebook

# Этапы работы
1. Загрузка и очистка данных.
2. Объединение информации о пользователях и платежах.
3. Расчёт конверсии для групп A и B.
4. Анализ воронки оплаты.
5. Проверка статистической значимости различий.
6. Визуализация результатов и формирование рекомендаций.

# Результаты
- Проанализировано 2 659 записей о платежах.
- Конверсия группы A — 49,8%.
- Конверсия группы B — 64,4%.
- Разница — около 14,6 процентного пункта.
- Получены статистически значимые различия между группами в рамках проведённого анализа.
